The MI-random rPQL algorithm is used to selected important fixed and random effects for Linear mixed models(LMMs) with incompleted data
Compution environment
The simulation and empirical studies were conducted on a high-performance computing cluster (supercomputer) using R version 4.2.1 under Linux. 
Jobs were submitted through SLURM on compute nodes equipped with dual Intel Xeon Gold 6338 processors (2 × 32 cores) and 128 GB RAM.
